# KUSE 模型评测看板

首页展示模型与分类的耗时、积分均值。点击单元格查看完整 Prompt 与 10 组执行记录。

数据快照：2026-10-10。均值仅统计已完成且指标为有效数值的记录。缺失值不计作零。

该目录的静态文件可通过 GitHub Pages 发布；不需要 ChatGPT 登录。

显示规则：耗时、积分及均值四舍五入显示整数；均值先按原始精度计算，再取整。CSV 导出使用同样的整数规则。数据文件保留原始精度以便核对。

质量评分入口位于平均积分之后，使用独立的 `quality.json` 与 `quality.js`。目前录入 Claude Haiku 5.5 的 80 条评分记录，其中 60 条已有最终评分，搜索研究和知识召回 20 条待提供回答。其他模型暂无评分，缺失值不计作零。质量分类均分与模型均分只对已有最终评分求均值。

评分明细保留完整 Prompt、最终评分、规则分、内容分、两项权重、封顶分、封顶前加权分、匹配产物、评分状态及核对依据，可按模型和分类浏览、搜索及导出 CSV。模型均分进入全部 80 条任务，分类单元格进入对应 10 条。

更新质量数据：运行相邻 source 目录的 `extract_quality.py`，同步生成的 `dist/quality.json` 到本目录，并更新 app.js 的质量数据版本参数及 index.html 的资产版本参数后推送发布分支。耗时/积分更新不覆盖质量数据。
